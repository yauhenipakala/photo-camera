# photo-camera
Simple demo for taking photo from webcam with JavaScript.

## Development

```sh
npm install
npm run dev      # start dev server at https://localhost:5173 (also on the local network)
npm run build    # build site to dist/
npm run preview  # serve the built site
```

## Deployment

Every push to `master` is built and deployed to Cloudflare Pages (project `photo-camera`) by `.github/workflows/deploy.yml`.
